# Conceptos Fundamentales de LLM

## Tokenización

Proceso mediante el cual el texto se convierte en unidades que el modelo puede procesar.

## Embeddings

Representaciones numéricas que permiten capturar relaciones semánticas entre elementos del lenguaje.

## Self-Attention

Mecanismo que permite al modelo identificar relaciones entre diferentes partes de una secuencia.

## Transformer

Arquitectura que permite procesar lenguaje mediante bloques de atención y transformaciones neuronales.

## Modelo Autoregresivo

El modelo aprende a predecir el siguiente token basándose en el contexto anterior.
